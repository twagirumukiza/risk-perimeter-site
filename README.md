# Le périmètre de risque n’est plus le SI

Mini-site éditorial bilingue (FR / EN) autour de la transformation du périmètre de risque cyber.

**Auteur :** Innocent TWAGIRUMUKIZA — Cybersecurity & Risk Management Consultant

## Fonctionnalités

- Bilingue FR / EN (sélecteur discret)
- Mode clair / sombre (respecte la préférence système + mémorisation)
- Contrôle de la taille du texte
- Design sobre, professionnel, orienté GRC / Risk Intelligence
- Schéma visuel de l’écosystème
- Cartes des 5 extensions du périmètre (Identités, Tiers, IA, Dépendances, Chaîne de valeur)
- Matrice des questions RSSI
- Référentiels : NIS2 · DORA · CRA · ISO 27001 · EBIOS RM · RGPD · ISO 42001
- 100 % statique, prêt pour GitHub Pages
- Responsive mobile / tablette / desktop

## Déploiement GitHub Pages

1. Créer un nouveau dépôt GitHub
2. Pousser le contenu de ce dossier à la racine du dépôt
3. Settings → Pages → Source : Deploy from a branch → `main` / root
4. Le site sera disponible à `https://<username>.github.io/<repo>/`
